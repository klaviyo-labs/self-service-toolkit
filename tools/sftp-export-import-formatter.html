Klaviyo SFTP Reimport

Converts a Klaviyo SFTP export CSV into an import-ready CSV. Emails are matched by profile_id from the segment CSV you provide. Rows with no email match are saved to a separate errors CSV.

  1. Use SFTP Export to export the desired metric's events from your Klaviyo account.
  2. Export a segment CSV capturing every profile that has performed this metric over all time.
    • Make sure to select Email and Klaviyo ID from the segment export screen
  3. Enter the Metric Name below, then upload both files to their respective drop zones.
  4. Click Convert. Once done, click Download CSV. If any rows were skipped, click Download Errors CSV to review them.
  5. Click Download Test CSV to get the first 5 rows, then upload that file to the Klaviyo SFTP server under Import → Events. Wait for it to process and verify the events look correct in Klaviyo before continuing.
    • If something doesn't look right, delete the metric in Klaviyo, adjust your inputs, and retry the process from step 1.
  6. Once the test looks good, upload the full Download CSV file to the Klaviyo SFTP server.
⚠️ We strongly recommend uploading the test file first. Importing millions of rows can take a long time — verifying with just 5 rows lets you quickly confirm your metric name, email mapping, and event data all look correct in Klaviyo before committing to the full import.
Working with a very large file that won't run in the browser? Download the Python version to run locally — requires Python 3.7+, no extra packages needed.
Applied to every row in the output as the "Metric Name" column.
